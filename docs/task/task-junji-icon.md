# 接入军机阁图标

> 功能文档：[技术设计 §5](../tech-design.md#5-client-侧设计)
> 创建：2026-11-13
> 基线：`f42f0ba`

## ① 需求与变更

根据用户提供的军机阁插画制作插件图标，放到 README 顶部。侧栏和插件管理页均展示军机阁标识。

## ② 精简技术设计

插画等比缩放后置入 384 × 384 透明画布，调节留白，让飞檐、桌案与书卷整体视觉居中。DSH 通过包清单 `icon` 字段加载包内资源，GitHub README 引用 `docs/assets` 下的同图副本。侧栏沿用 `sidebar.panellist`，把双层飞檐简化为适合 16–18 px 的单色图标，尺寸和颜色跟随宿主。

## ③ 测试用例与变化

- T1 新增人工检查。确认 README 图片路径有效，发行包带有清单指定的图标，PNG 小于 DSH 的 256 KiB 上限。
- T2 新增人工检查。在隔离 DSH 中打开插件管理页，核对卡片和侧栏图标实际显示。
- T3 沿用类型检查、构建和现有功能测试。

## ④ 技术实现

将透明 PNG 加入插件清单和发行包，仓库 README 顶部引用同图副本 `docs/assets/junji-icon.png`。客户端的 `JunjiIcon` 按宿主传入的尺寸绘制单色双层飞檐。

## ⑤ 验证结果

README 引用、包内图标和官方 DSH 界面均已核对。类型检查、构建及 20 项回归通过。具体步骤、截图和覆盖范围见 [测试报告](../../reports/junji-icon/01/test-report.md)。
