# 创建大臣时指定工作目录

> 功能定义：[军机阁技术设计 §4.1](../tech-design.md#41-agent-注册表registry)与[创建面板 §5](../tech-design.md#5-client-侧设计)
> 比较基线：`16aeb0f2994fbc729d68c091469a8e571fda9ae8`，插件工作区干净
> 创建：2026-11-15

## ① 需求与变更

用户要求创建大臣时可指定 `cwd`。创建表单、HTTP 和孔明工具共用这一可选参数。留空沿用军机阁默认目录，已有大臣使用原会话。档案和记忆沿用服务端数据目录。

## ② 精简技术设计

共用 Zod 协议为创建请求与档案提供可选 `cwd`。宿主复用 DSH 的绝对路径规范化，确认已存在且为目录后才保留档案。档案保留规范路径，以同一 `sessionId` 和目录续建。宿主复用 DSH 的工作区注册和归档服务。孔明工具采用现有宿主审批规则处理自定义工作目录，因为工作目录决定会话的文件写入范围。

## ③ 测试用例与变化

- T1 新增。HTTP 创建传入已有项目目录的别名，断言返回档案、真实会话头、归属工作区和原数据目录下的记忆文件。
- T2 新增。工作目录输入是相对路径、不存在的目录或普通文件时，创建失败且无新档案。
- T3 新增。创建途中失败后，从档案恢复原会话 ID 与工作目录。旧档案续建和省略目录的新建均使用军机阁默认目录。
- T4 新增。孔明工具传递 `cwd`，完全权限与单次确认沿用宿主规则。
- T5 沿用。执行军机阁现有注册表、记忆、委派和归档回归用例。

## ④ 技术实现

- `CreateAgentInputSchema` 和 `AgentRecordSchema` 定义可选 `cwd`，Web 表单、创建接口和孔明工具使用同一契约。
- `resolveAgentCwd` 检查目录，`JunjiRuntime.create` 保留其规范路径，`ensureAgent` 按档案创建专属会话并挂载对应工作区。档案与记忆路径仍由 `AgentStore` 管理。
- `AgentForm` 在创建时回传工作目录。`junji_create_agent` 指定目录时使用与删除操作相同的宿主权限检查函数。
