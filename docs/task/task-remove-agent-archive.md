# 删除军机阁成员时停止并归档会话

> 功能文档 [军机阁技术设计 §4.1](../tech-design.md#41-agent-注册表registry)
> 基线 `08f0650`。工作区已有的军机阁发送测试差异与本次修改独立。
> 日期 2026-11-11
> 状态 本地构建与宿主回归通过，运行实例待更新

## ① 需求与变更

用户要求删除成员时打断其专属会话任务，随后归档会话，并用新增用例验证打断及归档。成员档案与独立记忆仍随删除移除，历史会话保留。两种删除入口共用运行时。

## ② 精简技术设计

在既有串行删除流程中，按成员档案的会话 ID 定位活动 Agent，使用公开取消机制并等待空闲，再调用宿主原生归档。宿主继续处理会话下属活动，并阻止归档后的新轮次。归档报错时，成员档案留待重试。宿主明确报告会话不存在时，可以清理没有可归档会话的档案。

## ③ 测试用例与变化

| 用例 | 预期 |
| --- | --- |
| T1 新增 | 真实 DSH 会话正在生成且有待处理输入时删除成员。模型请求收到取消，轮次以 `aborted` 结束，队列清空，之后会话归档且历史保留。 |
| T2 新增 | 删除创建中断后尚无会话的成员档案成功。 |
| T3 新增 | 归档失败时删除报错，档案保留，修复故障后重试成功。 |

## ④ 技术实现

运行时 `removeRecord` 按已确认档案的会话 ID 请求取消，等待目标轮结束，调用原生归档并收敛归档期间的活动，再删除成员。孔明审批与界面删除文案同步列明停止和归档。新增真实宿主回归，模型使用可控的测试适配器。
