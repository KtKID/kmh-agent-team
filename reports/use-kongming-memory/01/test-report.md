## 改动覆盖率

Node v25.6.1 测试覆盖，整批合计。取源码 diff 新侧与 Node 覆盖行、分支记录的交集。军机阁两份 TS 用同一 TypeScript 版本重新生成源映射，先校验去掉 map 引用的生成代码与被测代码一致。合计可映射的改动行 **172/184（93.5%）**，相关分支 **32/43（74.4%）**。实际测试使用的共享实现来自同套源码，合计中按共享源码计一次。已删除代码、纯类型和文档不计入。构建与链接脚本单独通过真实打包检查，脚本路径覆盖率未采集。原始数据见 [军机阁 LCOV](evidence/coverage/junji.lcov)、[共享记忆 LCOV](evidence/coverage/memory.lcov)、[逐文件改动行与分支](evidence/coverage/changed-lines.txt)。

未命中主要是成员首次打开成功和绑定失败后的重试/日志分支、共享服务关闭后拒绝调用、重复绑定/重复刷新保护、相对路径拒绝，以及失活后的工具调用分支。未命中行号和分支号见逐文件数据。日常对话真实模型与沙盒加载后的产物仍需在 60080 核对。

## 验收回执

- 功能对账以用户确认的“替换记忆实现、按 Agent 隔离、其余行为沿用”为范围，已核对 §4.3、任务五段、旧用例退役位置及当前 T1–T4 证据。沙盒运行验证待新版加载。
- 技术复验独立重跑军机阁和共享插件覆盖用例。对照 `bindMemory` 的档案路径及 Agent 实例，确认无普通会话全局注册，发布由同一个服务实现，Cordis 用宿主 DSH 实例。共享默认值、旧提醒来源去重及独立发包均有对应证据。军机阁 lint 入口缺少可执行文件。主仓和沙盒版本未更新。
